# Reglas de interpretación (modo demostración)

Referencia: zona America/Bogota, la semana empieza el lunes.

| Expresión | Resultado |
|---|---|
| hoy / esta tarde / esta noche | hoy |
| mañana | hoy + 1 (no confunde "de la mañana") |
| pasado mañana | hoy + 2 |
| dentro de N días / en N días / en N semanas | hoy + N |
| este viernes | el viernes de esta semana en adelante (hoy, si hoy es viernes) |
| el próximo viernes / el viernes que viene | siguiente viernes después de hoy |
| el viernes | siguiente viernes; **si hoy es viernes, pregunta** |
| el martes de la próxima semana | martes de la semana calendario siguiente |
| el 25 | próximo día 25 (este mes o el siguiente) |
| 25 de diciembre / 25/12 / 25/12/2026 | sin año: próxima ocurrencia |
| antes del jueves / a más tardar el… | solo fecha de vencimiento |
| fin de mes | último día del mes |
| la próxima semana · el fin de semana · el próximo mes · en diciembre | **ambiguo: pregunta** |
| 31 de febrero | fecha inválida: lo dice y pide otra |

**Horas:** "9 de la mañana", "3 de la tarde", "8 y media de la noche", "9am", "4:30 p. m.", "16:00", "mediodía".
Si la hora es de 1 a 12 sin indicación ("a las 3"), **pregunta a. m. o p. m.**
Si hay hora pero no fecha, **pregunta el día**.

**Montos:** "$350.000", "350 mil", "1,5 millones", "un millón", "$1'200.000". Un número sin "$" ni unidad no se toma como dinero.

**Clasificación:** por palabras clave definidas en `src/domain/categories.ts`.
